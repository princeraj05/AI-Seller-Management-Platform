# AI Seller Management Platform

An AI-driven multi-channel e-commerce and seller management platform for managing products, inventory, orders, analytics, and sales channels (Amazon, Flipkart, Myntra, Own Website, POS).

## Features
- **Multi-Channel Management**: Unified view of Amazon, Flipkart, Myntra, Website & POS channels.
- **AI Studio & Product Generator**: AI-powered catalog generation, SEO optimization, and title/description drafting.
- **Inventory & Order Management**: Real-time stock tracking, order fulfillment, and returns ledger.
- **Analytics & AI Intelligence**: Sales performance overview, trend detection, profit analysis, and AI seller assistant.

## Tech Stack
- **Frontend**: React, Vite, TailwindCSS, Lucide Icons, React Router
- **Backend**: Node.js, Express.js, MongoDB / Mongoose

## Quick Start

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
